# Sahaba Youth Center — Weekend Qur'an School Registration

A single-page registration form for the Sahaba Youth Center's weekend Qur'an school.

- Parents fill out their info and up to three children's details.
- Submitting opens the parent's email app with everything pre-filled, addressed to the registrar.
- A "Print / Save as PDF" option is available for handing in a physical copy instead.

This is a static HTML page (`index.html`) with no build step, deployed on Vercel.
